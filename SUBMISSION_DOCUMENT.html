1. Executive Summary & Objective

The Weather Information Dashboard (AuraWeather) is an interactive single-page web application engineered to retrieve, parse, and present global real-time meteorological conditions and extended forecasts. The application is built entirely using native web standards without relying on external frontend frameworks or styling libraries.

The core objective is to deliver a smooth user experience where users can seamlessly look up any city, view accurate temperature and atmospheric parameters, consult hourly and 5-day projections, use their current GPS coordinates, and toggle between dark and light color modes.

3. 2-Week Implementation Timeline (Workspace Sheet)

Week 1: UI Development & API Integration

  • Directory Setup: Created modular project repository containing index.html, style.css, and app.js.
  • UI Design: Crafted a modern glassmorphic theme with backdrop filters, curated Google Fonts (Outfit & Inter), and fluid spacing.
  • Search Interface: Built search input with clear trigger and debounced auto-suggest dropdown.
  • API Research & Connection: Evaluated and connected to the Open-Meteo public API (100% free, no API key required, reliable CORS support).
  • Dynamic Data Binding: Created asynchronous fetch pipelines to translate city names to coordinates and display temperature, humidity, and wind stats.

Week 2: Features, Testing & Finalization

  • Loading Skeletons: Added shimmering CSS skeleton loaders to eliminate cumulative layout shifts (CLS).
  • Error Boundaries: Created graceful fallbacks for misspelled cities, network disconnection, and geolocation denial.
  • Extended Forecasts: Built the 24-hour hourly slider and the 5-day daily forecast cards with precipitation probability.
  • Device Geolocation: Connected navigator.geolocation with BigDataCloud client reverse geocoding.
  • Dark/Light Theme: Engineered CSS custom properties toggle saved directly in localStorage.
  • Recent Searches & Units: Implemented search history chip manager and seamless Celsius/Fahrenheit conversion.
  • Code Cleanup & Documentation: Cleaned all source code comments, verified responsive viewports, and prepared this final submission dossier.

  • Forecast Endpoint: https://api.open-meteo.com/v1/forecast?latitude={lat}&longitude={lon}¤t=temperature_2m,relative_humidity_2m,apparent_temperature,is_day,precipitation,weather_code,wind_speed_10m,wind_direction_10m,surface_pressure&hourly=temperature_2m,weather_code,is_day&daily=weather_code,temperature_2m_max,temperature_2m_min,sunrise,sunset,uv_index_max,precipitation_probability_max,precipitation_sum&timezone=auto
